# 回测方法与假设

## 信号与成交时间

默认短均线为 5 个交易日，长均线为 20 个交易日。仅使用当日及之前的收盘价。
短均线高于长均线时目标持仓为 1，否则为 0。均线相等时空仓。
在第 t 日收盘后形成的信号，只能在第 t+1 日开盘调整仓位。
前 20 个观测值用于预热，第 21 个观测值才可能进入评价区间。
日期筛选保留此前价格用于预热，但每次评价开始时的账户都持有现金。

## 收益计算

令 p_old 为上一交易日收盘持仓，p_new 为本日开盘成交后的持仓，取值均为 0 或 1。
本日价格分别为 O（开盘）、C（收盘），前日收盘价为 C_prev，单边成本率为 c：

```text
overnight_factor = 1 + p_old * (O / C_prev - 1)
intraday_factor  = 1 + p_new * (C / O - 1)
turnover        = abs(p_new - p_old)
net_return      = overnight_factor * (1 - c * turnover) * intraday_factor - 1
```

这种拆分使开仓前的隔夜上涨不被计入策略收益，平仓日开盘前的隔夜涨跌仍由原持仓承担。
成本在每次开盘买卖时扣除，持仓不变时不收费。默认 10 bps 是佣金和滑点的合并示例假设，
并非对真实费率的估计；未单独模拟卖出印花税、最低佣金或交易费用的历史变化。

买入持有基准在同一评价起始日开盘买入，支付相同单边成本，持有至最后收盘。
策略和基准的期末持仓均按市值计价，不强制清仓，因此期末未平仓头寸不扣卖出费用。
使用全仓/空仓的连续比例，不模拟整数股、100 股整手、资金规模、成交量或涨跌停限制。
该框架不是逐笔成交模拟器。

## 指标定义

- 累计收益：逐日净收益连乘减 1。
- 年化收益：期末净值的 252/N 次方减 1，N 为评价区间观测数。
- 年化波动率：每日净收益样本标准差乘以 sqrt(252)。
- 夏普比率：每日平均超额收益除以收益样本标准差，再乘以 sqrt(252)。
  年度无风险利率先换算为日利率，默认年度假设为 0；零波动率时输出 null/N/A。
- 最大回撤：净值相对历史峰值的最低跌幅，峰值序列包含初始本金 1，避免漏掉首日亏损。
- 持仓比例：评价日中开盘成交后持有股票的天数比例，不是资金加权换手率。

现金收益设为 0。年化数据对短样本非常敏感；缺失交易日不会被自动补齐，故实际使用时应先核对
交易日历和停牌情况。默认的 252 是计算假设，JSON 中记录的评价日期和天数可用于核查。

## 数据与可复现性

真实行情通过 AKShare 获取，默认采用前复权 OHLC。复权口径与数据供应方修订可能改变历史数据，
不应将这种下载方式视作严格的历史时点数据库。下载器保存代码、查询区间、复权方式、下载时间和版本。
每次运行记录输入文件 SHA-256、参数、环境版本，导出完整每日流水和交易事件。
原始行情默认留在本地，以便保留数据快照；不会自动上传到仓库。

仓库中的 synthetic_prices.csv 只用于流程验证，不对应平安银行或任何真实证券。
样例指标不用于证明策略盈利能力。单标的结果不能支持普遍有效性，进一步研究应采用多标的和独立样本，
并事先固定参数，避免将同一样本上的调参结果当作样本外表现。
